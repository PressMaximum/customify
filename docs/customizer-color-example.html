Customify — Palette System (Phase 2.10–2.13)

Interactive reference for the palette derivation engine in inc/colors-palette.php. User picks 6 source slots — the theme derives 13 more tokens via the rules below. Spec source: docs/color-token-derivation-spec.md + Customify chroma-cap extension. Tweak the 6 pickers to stress-test: every brand pair should land ≥ AA contrast on the matching foreground.

Derivation rules — baked in (mirrors theme implementation)

  • on-*Solid foreground (text on brand bg): max-contrast pick between #FFFFFF and #1A1A1A against the rendered color. For rgba sources: composite over base first, then pick.
  • *-containerSoft brand tint: solve % to land at OKLab L ≈ 0.93, then cap OKLab chroma at 0.04 (Customify extension — keeps high-chroma brands like yellow from staying saturated).
  • on-*-containerDarken brand tone (keep hue) until ≥ 4.5:1 vs the capped container. Guarantees AA regardless of brand luminance.
  • text-mutedmix(in oklab, text 70%, base)
  • bordermix(in oklab, text 14%, base) — decorative divider, ~1.35:1 vs base (WCAG-exempt).
  • border-strongSolve % to reach 3:1 vs base (iterative). For form input borders / functional control outlines (WCAG 1.4.11).

Hidden from picker (theme internals only): --customify-on-primary, --on-secondary, --on-accent, --on-surface, --on-primary-container, --on-secondary-container, --on-accent-container. Consumed by SCSS auto-wire (.has-{brand}-background-color → color: var(--customify-on-{brand})) so brand-bg blocks auto-flip text without designer picking.

    
Legacy back-compat (6 slugs: text, link, heading, background, light-gray, dark-gray): NOT in palette filter. Instead, SCSS shim rules in _blocks.scss emit .has-{legacy-slug}-color { color: var(--customify-X) } without !important — preserves 30K rendering while letting modern designer picks win.

  


  
Two honest limits: (1) The lightness target + chroma cap give consistent contrast & perception, but they can't fix "reads as brand vs grey" for low-chroma sources — a muted navy primary will produce a slightly grey container. That's perceptual physics, not a bug. (2) Whole derivation assumes light base; with a dark base, the container P-solve clamps to ~0.98 and containers ≈ pure brand. Dark-mode design requires inverted logic — documented in SPEC §8.12 as a Phase 3 follow-up.
